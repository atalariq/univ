Akan dibangun sebuah perpustakaan yang dapat digunakan untuk peminjaman buku baik itu buku fisik maupun buku digital. Pencatatan yang dilakukan pada sistem adalah data peminjam/anggota perpustakaan, data buku, data penulis, data penerbit, data pustakawan yang sekaligus menjadi admin, dan tentu saja data peminjaman/pengembalian. Peminjaman buku digital (ebook) juga harus tercatat oleh pustakawan seperti halnya buku fisik.

1. Lakukan analisis dengan menentukan entitas apa saja yang terlibat dalam sistem kemudian buatlah ERD (logical model) dari sistem di atas menggunakan Oracle Data Modeller!
2. Setelah dibuat logical model-nya konversikan (engineer) ke dalam relational model sehingga didapatkan desain basis data yang siap diimplementasikan! Selain tangkapan layar, sertakan juga hasil akhir dari seluruh tabel yang terbentuk dengan format berikut:
   Format: Namatabel (kolom1, kolom2, …dst)
   Contoh: Member (id, nama, alamat, …dst)
3. Tuliskan perintah SQL untuk membuat tabel-tabel yang ada (minimal 3), lengkap dengan primary key dan foreign key-nya! Sertakan hasil running SQL berupa tangkapan layar pada Oracle!

Hasil dikumpulkan dalam file pdf berisi nama, nim, dan jawaban (deskripsi hasil analisis, screenshot hasil oracle data modeller, dll).
