# PSD: P11 - Binary Search Tree, Depth First Search, dan Breadth First Search

Buatlah kedalam laporan yang meliputi:

1. Jelaskan secara detail apa yang dimaksud dengan Search Tree
   dan apa saja manfaatnya dalam ilmu komputer,
   khususnya dalam proses pencarian data.
2. Jabarkanlah algoritma dari:
   - Binary Search Tree (BST),
   - Depth-First Search (DFS),
   - dan Breadth-First Search (BFS).
3. Buatlah struktur Binary Search Tree (BST) berdasarkan nilai berikut:
   `[50, 30, 70, 20, 40, 60, 80, 100]`
   Gambarkan bentuk pohonnya secara manual (bisa dengan diagram atau teks).
4. Buatlah program Python yang mengimplementasikan BST dengan fitur berikut:
   - Menambahkan nilai ke dalam BST
   - Mencari sebuah nilai tertentu dalam BST
   - Menemukan nilai terbesar dan terkecil
   - Menampilkan hasil traversal:
     - Inorder
     - Preorder
     - Postorder
5. Buatlah program Python sederhana yang mengimplementasikan:
   - DFS menggunakan struktur graf berbasis dictionary
   - BFS menggunakan struktur graf berbasis dictionary
