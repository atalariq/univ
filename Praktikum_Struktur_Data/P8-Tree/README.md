
# PSD P9 - Tree

## Tugas

Buatlah program python untuk menampilkan silsilah
keluarga kalian masing-masing (dari kakek-nenek sampai dengan leafnya yaitu nama kalian)
menggunakan konsep Tree yang telah dipelajari.

Kemudian buatlah penjelasannya melalui laporan singkat yang diunggah dalam bentuk pdf.

Di laporan singkat tersebut juga terdapat gambar tree dari silsilah keluarga kalian
(bisa digambar menggunakan paint atau yang lainnya),

kemudian jelaskan juga:

- Predecessor
- Successor
- Ancestor
- Descendant
- Parent
- Child
- Sibling
- Subtree
- Size
- Height
- Root
- Leaf
- Degree

dari kalian. (Note: jika misal tidak memiliki sibling, jelaskan saja tidak mempunyai)
