Sebuah aplikasi smartphone menyimpan daftar kontak penggunanya menggunakan struktur data Linked List.
Setiap kontak memiliki informasi berupa nama, nomor telepon, dan alamat email.

+ Mengapa Linked List cocok digunakan untuk menyimpan daftar kontak dalam aplikasi ini?
+ Implementasikan dengan kode fungsi-fungsi Python yang memungkinkan pengguna untuk:
  - Menambahkan kontak baru.
  - Menampilkan daftar kontak yang tersimpan.
  - Menghapus kontak berdasarkan nama.
