# Praktikum Basis Data

Folder `pbd-praktikum-basis-data`, semester 2.

## Overview

Praktikum basis data dengan Oracle Database Express Edition 21c sebagai
lingkungan kerja. Urutan materi yang tersimpan di sini mulai dari perancangan
ERD, instalasi RDBMS, SQL, DDL, DML dan DQL, subquery dan view, trigger, lalu
PL/SQL function. Hampir setiap pertemuan menyimpan satu laporan praktikum yang
ditulis dengan Typst (`report.typ`) di folder pertemuannya, ditambah berkas SQL
dan aset gambar.

Pertemuan 3 dan 4 punya catatan tugas sendiri (`readme.md`), pertemuan 12 punya
`task.md` dan `learn.md` tentang trigger. Pertemuan lain hanya berisi laporan,
skrip SQL, dan PDF hasil ekspor, tanpa catatan terpisah.

Bahan ujian tidak disimpan per pertemuan. `uts/` berisi cheatsheet, skrip
`employee.sql` dan `praktikan.sql`, serta salinan modul Oracle Academy database
design. `2026-06-16-uas/` berisi berkas jawaban UAS dengan skrip DDL, seed, dan
query.
