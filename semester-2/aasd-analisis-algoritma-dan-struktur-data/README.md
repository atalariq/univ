# Analisis Algoritma dan Struktur Data

Folder `aasd-analisis-algoritma-dan-struktur-data`, semester 2.

## Overview

Mata kuliah ini membahas perancangan dan analisis algoritma melalui tujuh topik berurutan: analisis algoritma, divide and conquer, metode greedy, minimum spanning tree, dynamic programming, branch and bound untuk travelling salesman problem, dan kompresi data dengan algoritme Huffman. Tiap topik punya satu berkas PDF materi dan satu dek presentasi.

Penomoran dek presentasi tidak selalu sama dengan urutan pertemuan. Dek bernomor 01 sampai 05 memuat analisis algoritma, divide and conquer, greedy, dynamic programming, dan branch and bound, sedangkan materi MST dan Huffman punya dek sendiri tanpa nomor.

Folder `2026-06-06-tugas-pengganti-sebelum-uas/` memuat soal latihan pengganti sebelum UAS beserta jawaban dan berkas Typst-nya. Latihannya berisi soal dynamic programming dengan pendekatan Held-Karp untuk TSP.
