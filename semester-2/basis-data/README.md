# Basis Data

Folder `basis-data`, semester 2.

## Overview

Kuliah ini berjalan dalam enam pertemuan: pengantar basis data, entity relationship diagram, SQL, introduction to SQL, relational algebra, dan normalization. Materi SQL memakai dua berkas dari Silberschatz (chapter 3 dan chapter 4) ditambah satu materi SQL dari Stanford, sementara normalization punya dua berkas dengan nama hampir sama, `normalization` dan `normalize`.

Bahan pendukung sepanjang semester ada di `00-materials/`: modul Oracle Academy Database Foundations dan Database Design. Keduanya berisi subbab terpisah untuk setiap topik, mulai dari pengantar database, pemodelan data, sampai pemetaan model logis ke relasional.

Dua berkas tugas diletakkan di akar folder: `2026-06-07-tugas-basis-data-trpl-review-pra-uas.local.pdf` dan `2026-06-08-tugas-pra-uas.typ`. Keduanya soal review persiapan UAS, bukan materi pertemuan.
