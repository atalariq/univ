# Praktikum Struktur Data

Folder `psd-praktikum-struktur-data`, semester 2.

## Overview

Praktikum struktur data dalam bahasa Python, berurutan dari pretest, function,
sorting, stack, queue, dequeue, linked list, tree, map function, hash table,
sampai binary search tree. Setelah itu materi kelompok: tiap kelompok menyusun
slides salah satu topik (Huffman, trie, graph, searching, stack dan queue,
sorting, linked list, binary tree) dan mempresentasikannya. Urutan materi juga
tercatat di `moc.md`.

Tiap folder pertemuan menyimpan modul dari dosen di level folder, kode di
`src/`, dan laporan praktikum (`report.typ` atau `report/main.typ`). Beberapa
pertemuan punya lembar tugas `task.md` atau catatan tambahan seperti
`pseudocode.md` di pertemuan 4.
