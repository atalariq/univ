# Pemrograman Berorientasi Objek

Folder `pbo-pemrograman-berorientasi-objek`, semester 2.

## Overview

Mata kuliah ini membahas pemrograman berorientasi objek dengan Java, dari pengenalan konsep sampai package. Pertemuan 1 memperkenalkan OOP, pertemuan 3 membahas class dan object, lalu pertemuan 4 dan 5 masuk ke abstract class, interface, dan encapsulation.

Pertemuan 8 sampai 11 melanjutkan ke inheritance, polymorphism, exception dan error handling, serta package. Capaian pembelajaran di `00-materials/cheatsheet-uas/cpmk.txt` menyebut polymorphism, exception dan error handler, serta package sebagai CPMK 5 sampai 7.

Dua pertemuan berisi tugas pengganti, yaitu pertemuan 2 dan 6, dan pertemuan 7 dipakai untuk quiz pra UTS. Isinya jawaban studi kasus beserta berkas Typst dan diagram UML, bukan catatan kuliah. Cheatsheet UAS yang mencakup seluruh materi disimpan di `00-materials/cheatsheet-uas/` dalam beberapa versi berkas.
