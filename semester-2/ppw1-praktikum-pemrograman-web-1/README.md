# Praktikum Pemrograman Web 1

Folder `ppw1-praktikum-pemrograman-web-1`, semester 2.

## Overview

Praktikum pemrograman web sisi klien dan server dasar, dari HTML, link, frame,
table, form, stylesheet, layout responsive, Bootstrap, desain website, JavaScript,
PHP, sampai CRUD PHP dan penyerahan repo. Tiap folder pertemuan menyimpan modul
atau slides dari dosen, kode latihan di `src/` atau `exercises/`, lembar tugas
`task.md`, dan laporan praktikum berbasis Typst (`report.typ`).

Folder `00-materials/` menyimpan modul kuliah bab 1 sampai 14 dalam bentuk asli
dari dosen, ditambah dua modul tambahan CRUD PHP. Penomoran bab tidak sama dengan
nomor pertemuan: bab 10 dan 11 dipakai di pertemuan 10, bab 12 di pertemuan 11,
bab 13 dan 14 di pertemuan 12. Empat berkas modul bab (10, 11, 12, 14) identik
dengan salinan yang sudah ada di dalam folder pertemuan terkait.
