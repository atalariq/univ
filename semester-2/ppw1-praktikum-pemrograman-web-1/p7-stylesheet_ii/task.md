
# PPW1: Pertemuan 7 - Stylesheet II

## TUGAS 1: CSS Position — Layout Kartu Profil

Buat halaman HTML dengan elemen-elemen berikut menggunakan CSS Position:

1. Buat sebuah kartu profil dengan position: relative sebagai parent container (lebar 280px, tinggi 350px)
2. Di dalam kartu, tambahkan badge status ("Online 🟢") dengan position: absolute di sudut kanan atas
3. Tambahkan sticky navbar di bagian atas halaman yang tetap terlihat saat scroll
4. Tambahkan tombol "Back to Top" dengan position: fixed di pojok kanan bawah

> ⭐ Bonus: Tambahkan z-index agar elemen yang seharusnya di depan tidak tertutup elemen lain

## TUGAS 2: Flexbox — Halaman Landing Sederhana

Buat landing page dengan struktur berikut menggunakan Flexbox:

1. Navbar: Logo di kiri, menu di kanan, menggunakan justify-content: space-between
2. Hero Section: Teks di kiri, gambar/ilustrasi di kanan menggunakan Flexbox
3. Card Grid: Minimal 3 kartu produk/fitur yang menggunakan flex-wrap: wrap
4. Footer: 3 kolom dengan Flexbox dan gap

> ⭐ Bonus: Tambahkan @media query agar layout berubah menjadi satu kolom di layar kecil

## TUGAS 3: Animation & Transition — Komponen Interaktif

Buat halaman berisi komponen interaktif berikut:

1. Minimal 3 tombol dengan efek hover berbeda menggunakan transition (warna, transform, box-shadow)
2. Sebuah loading spinner menggunakan @keyframes dan animation
3. Sebuah elemen yang fade in saat halaman dibuka menggunakan animasi opacity
4. Gunakan CSS Variables untuk mendefinisikan palet warna dan gunakan di seluruh file

> ⭐ Bonus: Tambahkan animasi pada kartu yang berputar saat di-hover menggunakan transform: rotateY()
