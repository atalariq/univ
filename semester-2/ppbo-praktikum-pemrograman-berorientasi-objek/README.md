# Praktikum Pemrograman Berorientasi Objek

Folder `ppbo-praktikum-pemrograman-berorientasi-objek`, semester 2.

## Overview

Praktikum PBO dalam bahasa Java, berjalan dari pengantar dan pengenalan Java,
array, class, modifier, studi kasus sistem parkir, sampai inheritance. Hampir
tiap folder pertemuan menyimpan proyek Java (`src/`, `bin/`, `pom.xml` atau
`*.iml`), modul dan lembar tugas dari dosen (`module.local.pdf`,
`assignment.local.pdf`), serta laporan praktikum di `report/` atau `report.typ`.

Folder `px-tugas-akhir-game-runewater.local/` memuat tugas akhir kelompok berupa
game Runewater: README kelompok dengan daftar anggota dan tautan repo, demo
video, sumber game, dan slides. Nomor pertemuannya tidak diketahui, jadi awalannya
tetap `px-`.

Dua berkas masih di level mata kuliah. `tugas-akhir-teori-pbo.local.pdf` adalah
soal tugas akhir teori. `ppbo.excalidraw` berisi diagram silsilah keluarga
(kakek-nenek, orang tua, anak), yang isinya lebih dekat ke tugas tree pada
praktikum struktur data daripada ke materi PBO, jadi tidak dipindahkan ke
pertemuan mana pun.
