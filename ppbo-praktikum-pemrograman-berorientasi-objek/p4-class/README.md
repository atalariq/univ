# Laporan Praktikum Pertemuan 4 Kelas B2

Kerjakan soal latihan nomor 2 tentang ScoreManager dan 2 soal tugas pertemuan ke-4. Kumpulkan dalam bentuk laporan praktikum!

## Soal Latihan

1. Buatlah sebuah program untuk membuat class pegawai, yang memiliki atribut nama,
   umur, dan gaji. Selain itu, terdapat juga sebuah atribut static yang digunakan untuk
   penanda seberapa banyak objek pegawai yang telah dibuat. Outputkan methode setiap
   objek sehingga output menjadi “Pegawai {nama} berumur {umur} memiliki gaji sebesar
   {gaji}”.
2. Buatlah sebuah scoreManager, dimana kita bisa menambahkan nilai dari setiap anak,
   kemudian buatlah juga method untuk menjumlahkan total semua nilai, mencari rata-rata
   nilai, nilai tertinggi dan terendah, serta perbedaan nilai tertinggi dan terendah.
3. Buatlah sebuah program menggunakan enum untuk setiap mata uang Indonesia kemudian
   simpan menggunakan map. Outputkan banyak uang pada setiap nominal kertas,
   kemudian outputkan juga jumlah total nominal uang.

## Soal Tugas

1. Buatlah Sebuah kelas bernama pegawai yang memiliki atribut nama, posisi, lama kerja.
   Kelas pegawai memiliki method ambil slip berdasarkan posisi.
   Kelas kantor memiliki list nama pegawai, rata-rata gaji, jumlah gaji, jumlah pegawai.
   Kantor dapat memecat pegawai dan menambahkan pegawai.
2. Buatlah class RunningTracker, dimana kita bisa mencatat jarak lari setiap hari (dalam km).
   Kemudian buat method untuk:
   - Menambahkan jarak lari
   - Menghitung total jarak
   - Menghitung rata-rata jarak
   - Mencari jarak terjauh
   - Mencari jarak terpendek
   - Menghitung selisih jarak terjauh dan terpendek
