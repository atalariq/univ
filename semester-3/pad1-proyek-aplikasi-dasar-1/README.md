# Proyek Aplikasi Dasar 1

Folder `pad1-proyek-aplikasi-dasar-1`, semester 3.

## Overview

Mata kuliah ini berisi satu proyek perangkat lunak yang dikerjakan berkelompok
sepanjang semester, mulai dari pengumpulan kebutuhan sampai penyerahan. Proyek
yang kuambil adalah sistem katalog dan pemesanan untuk kebutuhan internal
Citra Productions.

Folder ini sengaja tidak menyimpan kode. Kode dan dokumen arsitekturnya ada di
repo proyek terpisah, `citra-productions`, karena dokumen itu dipakai saat
membangun aplikasi, bukan saat menulis laporan. Yang tersimpan di sini adalah
catatan perjalanan pengerjaannya.
