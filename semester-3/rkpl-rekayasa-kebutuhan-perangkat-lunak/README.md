# Rekayasa Kebutuhan Perangkat Lunak

Folder `rkpl-rekayasa-kebutuhan-perangkat-lunak`, semester 3.

## Overview

Mata kuliah ini membahas siklus kebutuhan perangkat lunak, dari menggali kebutuhan stakeholder sampai memvalidasikannya. Materi yang tersedia berjalan dari pengantar dan fondasi requirements engineering (p02), elicitation tahap pertama beserta pembaruan proses RE (p03), elicitation tahap kedua (p05), lalu requirements analysis and modeling (p06).

Setelah itu masuk ke Viewpoint-Oriented Requirements Definition atau VORD (p07) dan requirement validation (p08). Catatan p07 memuat tugas analisis VORD untuk proyek PAD beserta hasilnya, mulai dari daftar viewpoint, service list, analisis data dan control, sampai pengisian template VORD. Catatan p08 membedakan validation dan verification, lalu merinci enam tahap requirements review, empat tipe masalah beserta aksinya, checklist reviewer, dan teknik validasi.

Folder p09 berisi tugas validasi kebutuhan berupa studi kasus dan draft laporan. Folder `00-materials/` menyimpan rencana pembelajaran dan buku teks Software Requirements edisi ketiga sebagai rujukan sepanjang semester.
