# Kompendium Praktikum PPWL

Dokumen Typst yang merangkum seluruh instruksi praktikum website portofolio:
modul, implementasi repository, laporan per pertemuan, dan perbandingan modul vs
laprak.

## Build

```sh
typst compile compendium.typ compendium.pdf
```

## Sumber

- Modul: `../00-materials.local/` dan `module.local.pdf` tiap folder pertemuan.
- Laporan: `../p4-*` sampai `../p10-*`.
- Kode: repository `ppwl-portfolio`, commit pada tabel commit map.
