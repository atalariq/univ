# Praktikum Pemrograman Web Lanjut

Folder `ppwl-praktikum-pemrograman-web-lanjut`, semester 3.

## Overview

Praktikum ini membangun aplikasi web dinamis dengan Laravel di atas MySQL, mengikuti pola MVC. Satu proyek portofolio dipakai lintas pertemuan dengan branch terpisah per pertemuan, sedangkan kodenya tinggal di repository lain sesuai `AGENTS.md` mata kuliah ini. Folder pertemuan memuat catatan, laporan Typst, aset tangkapan layar, dan modul dari dosen.

Urutan materinya: instalasi Laravel (p02), CRUD PHP tanpa framework (p03), routing dan view Blade (p04), controller dan model (p05), CRUD Laravel (p06), Eloquent ORM (p07), seeder dan pagination (p08), authentication dan middleware (p09), dashboard dengan unggah berkas dan galeri (p10), search, filter, dan sorting (p11), lalu REST API dengan rate limit (p12). p03 menyimpan kode PHP mentah di `src/`, pertemuan lain menyimpan kode di repo terpisah.

Materi dosen dikumpulkan di `00-materials.local/` dalam bentuk modul dan slide dari pertemuan 2 sampai 14. Beberapa berkas di sana salinan identik dengan `module.local.pdf` di folder pertemuan, terlihat dari hash yang sama. `00-compendium/` adalah proyek Typst terpisah berisi kompendium catatan praktikum.
