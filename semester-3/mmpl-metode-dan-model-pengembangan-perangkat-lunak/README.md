# Metode dan Model Pengembangan Perangkat Lunak

Folder `mmpl-metode-dan-model-pengembangan-perangkat-lunak`, semester 3.

## Overview

Mata kuliah ini membahas cara membangun perangkat lunak secara terstruktur, dari proses pengembangan dan model sekuensial klasik sampai metodologi iteratif dan kerangka kerja Agile. Catatan pertemuan 2 memakai kerangka software engineering layers (quality focus, process, methods, tools) lalu menurunkan software process menjadi specification, design and implementation, dan seterusnya.

Setelah fondasi proses, urutan materi berjalan ke model Waterfall, incremental dan iterative, Spiral, RAD, lalu Agile Manifesto beserta framework turunannya. Pertemuan 7 memuat RAD (James Martin, 1991) lengkap dengan fase dan pendekatannya, kemudian Agile Manifesto dengan empat values dan dua belas principles. Pertemuan 12 merangkum lima framework Agile (Crystal, DSDM, FDD, Nexus, SAFe) dalam catatan bertopik plus tabel perbandingan lintas framework.

Folder p13 memuat berkas pendukung per framework (`crystal-method.md`, `dsdm.md`, `fdd-expert-brief.md`, `fdd-suplemen.md`, `nexus.md`, `safe.md`), rekaman masukan expert brief, tugas kelompok berisi lima studi kasus, dan kuis Kahoot. Folder p03 menyimpan dua paper Waterfall dan laporan Typst tugas pengganti kuliah minggu ke-3. Folder `00-materials/` berisi lima slide dosen yang dipakai sepanjang semester.
