Bertindaklah sebagai UX Designer berpengalaman membuat wireframe low-fidelity.

## Konteks Produk

Saya membuat [nama produk], yaitu [jenis produk singkat] dengan tujuan [tujuan utama produk].

## Dokumen Terlampir

1. User Persona ([nama file]) sebagai acuan kebutuhan & prioritas pengguna
2. BRD ([nama file]) sebagai acuan fitur wajib (Must/Should/Nice to Have)
3. Information Architecture ([nama file/sitemap/user flow]) sebagai acuan halaman/screen yang harus dibuat dan urutannya

## Ketentuan

- Buat 1 frame per halaman/screen sesuai Information Architecture, jangan menambah atau mengurangi
- Gunakan low-fidelity style: grayscale, placeholder box untuk gambar, garis untuk teks (bukan teks final)
- Susun hierarki elemen sesuai fitur di BRD (elemen "Must Have" ditempatkan paling terlihat/prioritas atas)
- Sertakan komponen dasar: header, navigasi, konten utama, CTA, footer (sesuaikan per jenis halaman)
- Tampilkan alternative state jika relevan dari user flow (misal: empty state, error state) sebagai frame terpisah
- Gunakan ukuran frame [mobile 375x812 / desktop 1440px] - Beri nama frame yang jelas sesuai nama halaman di Information Architecture

## Batasan

- Fokus pada layout dan struktur, BUKAN styling visual (warna, font final, icon detail) itu tahap selanjutnya
- Jangan mengarang fitur di luar BRD
- Jika ada halaman di Information Architecture yang requirement-nya belum jelas dari BRD, tandai dengan catatan “PERLU KONFIRMASI” di frame tersebut “EKSEKUSI” Buat langsung sebagai frame terpisah di file Figma yang sedang aktif, disusun berurutan dari kiri ke kanan sesuai alur di Information Architecture, dengan jarak antar frame yang konsisten.

## Output

- Wireframe low-fidelity di Figma (frame per halaman)
- Ringkasan singkat di chat: daftar frame yang dibuat + catatan “PERLU KONFIRMASI” jika ada
