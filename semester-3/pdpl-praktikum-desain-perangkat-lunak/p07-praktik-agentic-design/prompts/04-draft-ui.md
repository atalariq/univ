## Konteks Produk

Desain UI untuk [nama produk/fitur]: [jenis produk & tujuan utama, 1-2 kalimat].

## Dokumen Terlampir (acuan utama)

1. User Persona ([nama_file]) target pengguna, kebutuhan, pain point
2. BRD ([nama_file]) fitur wajib, alur bisnis, batasan/validasi
3. User Flow/Sitemap ([nama_file]) ikuti urutan & transisi screen persis
4. Wireframe ([nama_file]) acuan struktur layout & hierarki info. Jangan ubah struktur, hanya perkaya visual
5. Moodboard ([nama_file], jika ada) acuan warna, tipografi, tone, mood

## Gaya Visual

1. Deskripsi: [Style] + [Mood] + [Layout] + [Brand Personality]
2. Warna: Primary [hex] | Secondary [hex] | Accent [hex] | Neutral [hex]
3. Font: [font heading] untuk judul, [font body] untuk isi

## Prioritas Acuan

1. Struktur & alur mengikuti Wireframe dan User Flow/Sitemap secara ketat
2. Fitur & konten mengikuti BRD
3. Gaya visual mengikuti Moodboard, deskripsi visual, warna, font
4. Relevansi sesuaikan dengan User Persona

## Batasan

Jika ada requirement BRD yang belum jelas dipetakan ke elemen visual, tandai “PERLU KONFIRMASI”, jangan mengarang.

## Output

Format: [mobile 375x812 / desktop 1440px] Sertakan komponen interaktif (button, input, card) yang reusable.
Tampilkan varian state: default, loading, error, success (jika relevan).
