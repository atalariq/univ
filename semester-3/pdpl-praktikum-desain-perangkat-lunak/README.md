# Praktikum Desain Perangkat Lunak

Folder `pdpl-praktikum-desain-perangkat-lunak`, semester 3.

## Overview

Praktikum ini mendampingi kuliah Analisis dan Desain Perangkat Lunak dengan penekanan pada praktik desain antarmuka dan dokumen desain. Materi pertemuan 2 berisi slide persona dan empathy sebagai bahan awal pemahaman pengguna. Pertemuan 5 membahas fundamental user interface design, dan pertemuan 6 membahas atomic design serta design system, termasuk alasan design system dibutuhkan pada proyek besar dan sikap terhadap hasil AI.

Pertemuan 7 membahas praktik desain dengan bantuan AI. Catatannya memuat design thinking, prinsip koreksi dan kurasi hasil AI, serta urutan drafting dari user research, persona, BRD, information architecture, wireframe, sampai desain. Folder `prompts/` menyimpan empat prompt drafting untuk BRD, IA, wireframe, dan UI. Buku panduan merancang UI dengan AI tersimpan di folder yang sama.

Pertemuan 12 berisi tugas usability testing memakai Maze terhadap prototipe Figma, dengan skenario, start dan goal screen, post-test questionnaire, serta analisis metrik. Materi tiap pertemuan disimpan di folder pertemuannya masing-masing, bukan di `00-materials/`.
