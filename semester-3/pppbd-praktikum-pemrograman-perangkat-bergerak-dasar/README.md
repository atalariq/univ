# Praktikum Pemrograman Perangkat Bergerak Dasar

Folder `pppbd-praktikum-pemrograman-perangkat-bergerak-dasar`, semester 3.

## Overview

Praktikum ini membangun aplikasi Android dengan Kotlin, mulai dari layout XML sampai Jetpack Compose. Tiap pertemuan punya proyek dan repository sendiri, sesuai `AGENTS.md` mata kuliah ini yang menyebut kode tinggal di luar repo catatan. Folder pertemuan memuat `module.local.pdf` dari dosen, laporan praktikum Typst, dan aset gambar yang dipakai laporan.

Rangkaian topiknya: layout Relative dan Constraint (p03), Activity dan Intent (p04), Tab Layout dengan menu options, fragment, dan custom style (p06), Bottom Navigation dengan fragment pada aplikasi MyShop (p08), RecyclerView (p09), Retrofit (p10), Jetpack Compose dengan ViewModel (p11), dan CRUD (p12). Catatan p03 berupa `NOTES.md` dan `LOG.md` berisi langkah praktikum serta catatan troubleshooting. p08 menambahkan `notes.md` yang menjelaskan cara laporan disusun, sumber snapshot `snippets/`, dan asal setiap gambar di `assets/`.

Tidak ada folder `00-materials` karena materi dosen semester ini disimpan sebagai berkas `.local` di folder pertemuannya masing-masing. Berkas rujukan teori dan template laporan juga tinggal di folder pertemuan terkait.
