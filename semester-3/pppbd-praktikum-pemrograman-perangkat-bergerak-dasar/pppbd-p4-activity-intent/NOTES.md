# Pertemuan 4 - Activity & Intent


## Penugasan

Gunakan tugas pertemuan 3 (layouting).
Implementasikan navigasi menggunakan startActivity dan launcher pada UI.
1. ketika button Edit Profile di click, buka halaman untuk melakukan edit nama dan edit bio.
   Ketika proses edit selesai dan disimpan, navigasikan halaman kembali ke halaman awal dengan data nama dan data bio sudah berubah.
2. ketika icon foto di klik, navigasikan ke halaman baru yang menampilkan foto dan nama akun.

Format pengumpulan:
Buat sebuah tutorial (seperti pada modul) yang mendeskripsikan bagaimana aplikasi Anda dibuat secara sistematis.
Tutorial dilengkapi dengan:
- url repository,
- url video demo, dan
- penjelasan lengkap mengenai kode yang digunakan.
