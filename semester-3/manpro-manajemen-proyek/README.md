# Manajemen Proyek

Folder `manpro-manajemen-proyek`, semester 3.

## Overview

Mata kuliah ini membahas pengelolaan proyek pengembangan perangkat lunak dengan PMBOK sebagai kerangka utama. Materi yang tersedia baru mencakup tiga pertemuan: perkenalan kontrak belajar dan silabus, pengantar manajemen proyek, serta manajer dan tim proyek.

Buku PMBOK Guide edisi ke-7 tahun 2021 tersimpan di `00-materials/` sebagai rujukan sepanjang semester. Tidak ada tugas atau dokumen proyek lain di folder ini, sehingga topik seperti project charter, WBS, penjadwalan, dan manajemen risiko belum punya jejak.
