# PPW1: Pertemuan 11 - PHP

Buatlah laporan praktikum terkait materi Javascript yang memuat :

1. Penjelasan tiga tugas praktikum pada modul 11 PHP:
   1. Buat file PHP yang menampilkan profil dirimu (nama, NIM, prodi, asal kota)
      dalam tabel HTML yang rapi menggunakan variabel PHP.
   2. Buat fungsi hitungIMT(Sberat, Stinggi) yang menghitung Indeks Massa Tubuh
      dan mengembalikan kategorinya ('Kurus', 'Normal', 'Gemuk', 'Obesitas').
      Tampilkan hasilnya di halaman HTML.
   3. Buat halaman yang menampilkan nama bulan sekarang dan berapa hari tersisa
      di bulan ini menggunakan fungsi date().
2. Sebuah kalkulator menggunakan Javascript. Konsep kalkulatornya memiliki
   fungsi untuk menjumlahkan, mengurangi, dan membagi bilangan. Secara sekilas,
   kalkulator ini akan memiliki:
   - 2 inputan untuk bilangan pertama dan kedua;
   - 4 tombol dengan fungsi untuk tambah, kurang, bagi, kali;
   - dan terakhir ada bagian untuk output hasil perhitungannya.
