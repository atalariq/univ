# PBD: P12 - Trigger

Kerjakan tugas latihan Praktikum Basis Data menggunkan Oracle Databse Express Edition 21c

1. Buatlah trigger yang akan menyimpan data pegawai ke suatu tabel
   (buat tabel terlebih dahulu) jika ada data pegawai yang dihapus!
2. Buatlah trigger untuk menyimpan data perubahan harga pada tabel produk ketika ada perubahan harga.
   Buat tabel price_change dengan kolom product_id, date_updated, old_price, new_price sebagai penyimpan datanya!

Resource: [OT- Trigger](https://www.oracletutorial.com/plsql-tutorial/oracle-trigger)

Output: `trigger.sql` (schme oracle-xe-21c)
