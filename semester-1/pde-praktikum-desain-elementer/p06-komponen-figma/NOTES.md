# Pertemuan 6: Komponen Figma

Tujuan pertemuan adalah memahami prinsip dasar pembuatan komponen UI dan variabel, membuat component library di Figma, serta menerapkan konsistensi dan reusability dalam desain UI (hlm. 2).

Komponen didefinisikan sebagai elemen yang dapat dipakai kembali di seluruh desain sehingga desain tetap konsisten dan mudah dikelola (hlm. 4). Komponen dapat dibuat dari layer atau objek apa pun, termasuk button, icon, dan layout. Ada dua aspek yang perlu dibedakan: main component, yaitu komponen yang mendefinisikan properti atau sifat dasar, dan instance, yaitu salinan komponen utama yang dipakai dalam desain. Instance tetap tertaut pada komponen utamanya sehingga menerima pembaruan yang dibuat pada komponen tersebut (hlm. 4).

Materi tidak merinci langkah teknis pembuatan komponen atau variabel di Figma; bagian setelah penjelasan itu hanya berisi tautan resource (hlm. 5-6). Yang bisa dipelajari dari deck ini adalah konsep dan bentuk latihannya.

Latihan yang diminta adalah membuat component library berisi minimal tiga kelompok komponen (hlm. 7). Navigation bar harus punya minimal tiga menu seperti Home, Search, dan Profile, dalam beberapa state: Active, Inactive, dan Hover. Button harus punya tiga varian, yaitu Primary, Secondary, dan Disabled, dengan state Default, Hover, dan Pressed. Form input harus punya text field dengan kondisi Default, Focus, dan Error, serta dropdown dengan minimal dua opsi. Semua komponen disusun pada halaman Component Library dan dikumpulkan sebagai link Figma beserta ekspor PDF (hlm. 7).

Dari daftar tugas itu terlihat bahwa state dan varian diperlakukan sebagai bagian dari satu komponen, bukan komponen terpisah, dan bahwa konsistensi dicapai dengan menyimpan semua versi di satu halaman rujukan. Tujuan pembelajaran menyebut variabel, tetapi deck tidak menjelaskan apa itu variabel maupun cara membuatnya.

## Poin kunci

- Komponen adalah elemen yang dapat dipakai ulang di seluruh desain (hlm. 4).
- Main component mendefinisikan properti dasar; instance adalah salinannya yang tetap tertaut (hlm. 4).
- Komponen bisa dibuat dari layer atau objek apa pun, termasuk button, icon, dan layout (hlm. 4).
- Latihan meminta minimal tiga kelompok komponen: navigation bar, button, dan form input (hlm. 7).
- Tiap komponen dilengkapi state atau varian, seperti Active, Inactive, Hover, dan Disabled (hlm. 7).
- Semua komponen dikumpulkan pada satu halaman Component Library (hlm. 7).

## Istilah

- komponen: elemen desain yang dapat dipakai ulang.
- main component: komponen utama yang menyimpan properti dasar.
- instance: salinan komponen utama yang dipakai dalam desain.
- component library: kumpulan komponen untuk satu proyek atau brand.
- state: kondisi tampilan komponen, misalnya Hover atau Pressed.
- varian: versi berbeda dari satu komponen, misalnya Primary dan Secondary.
- reusability: sifat dapat dipakai ulang.
