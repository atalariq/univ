# Pertemuan 7: User Flow

User flow didefinisikan sebagai peta visual perjalanan pengguna yang menunjukkan langkah-langkah untuk menyelesaikan tugas spesifik dalam suatu produk atau layanan (hlm. 4). Fungsinya sebagai cetak biru strategi desain UX: membantu desainer dan manajer produk memahami interaksi pengguna dan menemukan hambatan sebelum tahap produksi (hlm. 4). Manfaatnya mencakup peningkatan pengalaman pengguna, komunikasi yang lebih jelas antartim, efisiensi proses desain, dan prioritisasi fitur yang paling berdampak (hlm. 6).

Tiga tipe diagram dibedakan. Task flow berfokus pada satu jalur penyelesaian tugas dan cocok ketika semua pengguna mengerjakan tugas dengan cara yang sama (hlm. 8). Wire flow menggabungkan flowchart dengan wireframe sehingga perpindahan antarlayar terlihat nyata, dan disebut sangat efektif untuk aplikasi mobile karena ukuran layarnya kecil (hlm. 9). User flow adalah tipe paling lengkap karena mengakui bahwa pengguna bisa punya cara berbeda untuk mencapai tujuan yang sama (hlm. 10).

Penyusunan user flow dimulai dengan memahami pengguna: kebutuhan utama, masalah yang ingin dipecahkan, fitur yang dianggap penting, pertanyaan yang muncul saat pertama kali memakai produk, dan informasi yang perlu disediakan (hlm. 12). Setelah itu ada tiga bagian: entry point, yaitu jalur awal pengguna masuk, yang untuk website lebih beragam (hasil pencarian, iklan, tautan) dan untuk aplikasi lebih terbatas (app store) (hlm. 13); steps to completion, yaitu rangkaian langkah inti seperti login, onboarding, dan halaman utama, yang harus dijaga tetap sederhana (hlm. 14); serta the final interaction, yaitu layar terakhir yang menandai tugas selesai (hlm. 15).

Materi menegaskan tidak ada aturan baku dalam membuat user flow; yang penting adalah konsistensi bentuk dan kejelasan alur (hlm. 17). Empat elemen bentuk dijelaskan: rectangle untuk halaman atau layar, lines with arrows untuk menghubungkan bentuk dan menentukan arah alur, circle untuk aksi atau tindakan yang biasanya dilabeli kata kerja, dan diamond untuk keputusan dengan cabang jawaban ya dan tidak (hlm. 18-21).

## Poin kunci

- User flow memetakan langkah pengguna untuk menyelesaikan satu tugas (hlm. 4).
- Manfaatnya: pengalaman pengguna lebih baik, komunikasi jelas, efisiensi desain, dan prioritisasi fitur (hlm. 6).
- Task flow hanya satu jalur, wire flow memakai wireframe, user flow menerima banyak jalur (hlm. 8-10).
- Struktur user flow terdiri atas entry point, steps to completion, dan final interaction (hlm. 13-15).
- Entry point di web lebih beragam daripada di aplikasi (hlm. 13).
- Rectangle untuk layar, circle untuk aksi, diamond untuk keputusan, dan garis panah untuk alur (hlm. 18-21).

## Istilah

- user flow: peta visual langkah pengguna menyelesaikan tugas.
- task flow: diagram alur satu jalur untuk satu tugas.
- wire flow: gabungan flowchart dengan wireframe.
- entry point: jalur awal pengguna masuk ke produk.
- steps to completion: rangkaian langkah inti menuju tujuan.
- final interaction: layar terakhir yang menandai tugas selesai.
- decision diamond: bentuk untuk titik keputusan bercabang.
