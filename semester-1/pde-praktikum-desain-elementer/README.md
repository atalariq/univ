# Praktikum Desain Elementer

Folder `pde-praktikum-desain-elementer`, semester 1.

## Overview

Praktikum ini membahas dasar-dasar desain antarmuka, dari prinsip desain sampai mini project. Materi pertemuan yang tersimpan mencakup prinsip desain, elemen dasar UI seperti layout, grid, spacing, dan visual hierarchy, warna dan tipografi, komponen Figma, user flow, logo, mockup, serta graphic standard manual.

Pertemuan 11 dan 12 sama-sama bertopik graphic standard manual. Catatan pertemuan 12 menyebut materinya digabung ke pertemuan 11. Folder ini belum punya materi semester, jadi semua berkas materi berada di folder pertemuan masing-masing.
