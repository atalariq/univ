# Algoritma dan Pemrograman

Folder `alpro-algoritma-dan-pemrograman`, semester 1.

## Overview

Deck kuliah di folder ini tersusun per pertemuan, dari aturan perkuliahan sampai searching. Pertemuan 1 membahas pengertian algoritma, konsep pemrograman terstruktur, dan teknik penyajian algoritma. Pertemuan 2 memperkenalkan struktur data lewat soal rata-rata sekumpulan bilangan bulat dan pencarian nilai terbesar, lengkap dengan flowchart dan pseudocode.

Pertemuan 3 sampai 8 membahas perkakas bahasa: tipe data, variabel, dan operasi I/O di Python; variabel dan operator; struktur algoritma repetition dengan contoh C++ dan Python; tipe data array; prosedur dan fungsi; serta fungsi rekursif, class, dan modul.

Pertemuan 9 sampai 11 masuk ke pengolahan data: sorting dengan selection, bubble, insertion, merge, dan quick sort; sorting bagian kedua dengan heap sort; lalu searching dengan sequential search, binary search, dan hashing. Satu berkas materi gabungan sorting dan searching disimpan di `00-materials/` karena tidak terikat satu pertemuan.
