# Pertemuan 9: Microsoft Word I

Modul ini adalah bagian pertama pelatihan Microsoft Word 2019 dan berfokus pada pembuatan dokumen serta pengenalan antarmuka. Word dijelaskan sebagai program untuk membuat dokumen berkualitas profesional, termasuk mengetik, memformat teks, memperbaiki kesalahan, dan menampilkan hasil sebelum dicetak. Modul menyebut Word 2019 didesain ulang dari versi sebelumnya, dengan tampilan Read Mode yang lebih bersih dan penyesuaian lebar kolom mengikuti ukuran layar (hlm. 1).

Antarmuka Word dijabarkan bagian demi bagian: Quick Access Toolbar yang tidak bergantung pada Ribbon, Title Bar, akun Microsoft untuk penyimpanan daring, tiga opsi tampilan Ribbon (Auto-hide, Show Tabs, Show Tabs and Commands), tombol jendela, tab, Ribbon, grup, dialog box launcher, ruler untuk margin, bidang kerja, serta status bar yang menampilkan jumlah halaman, jumlah kata, bahasa, tombol view, dan persentase zoom (hlm. 2-3). Word dapat dibuka lewat Start Menu, ikon shortcut di desktop, atau tombol keyboard dengan menekan logo Windows lalu W dan Enter (hlm. 3-5).

Pembuatan dokumen dibedakan menjadi dokumen kosong dan dokumen dari template yang dapat dicari berdasarkan kata kunci (hlm. 5-6). Penyimpanan dibahas dalam beberapa situasi: menyimpan berkas baru lewat File lalu Save As, Browse, penamaan, dan pemilihan tipe Word Document, menyimpan dokumen yang sudah ada dengan Save, menyimpan dengan nama berbeda, serta menyimpan ke format lain seperti doc dan PDF (hlm. 7-9). Ada juga penyimpanan dengan password melalui Tools dan General Options, yang menyediakan password to open, password to modify, dan opsi read only recommended, ditambah cara cepat dengan Ctrl+S atau ikon disket di Quick Access Toolbar dan penyimpanan ke OneDrive (hlm. 9-10).

Bagian terbesar modul memetakan isi tab Ribbon. Tab Home berisi grup Clipboard, Font, Paragraph, Styles, dan Editing, lengkap dengan pintasan seperti Ctrl+X, Ctrl+C, Ctrl+V, Ctrl+B, Ctrl+I, Ctrl+U, serta perataan dan penomoran (hlm. 11-14). Tab Insert memuat Pages, Tables, Illustrations, Add-ins, Media, Links, Comments, Header & Footer, Text, dan Symbols (hlm. 15-19). Tab Design mengatur tema, style set, warna, font, spasi paragraf, dan latar halaman berupa watermark, page color, serta page borders (hlm. 19-22). Tab Layout mencakup page setup, indentasi dan spacing, serta pengaturan posisi objek, sedangkan tab References menangani daftar isi, footnote, sitasi, caption, bibliography, index, dan table of authorities (hlm. 22-28).

## Poin kunci

- Word 2019 dipakai untuk membuat dan memformat dokumen profesional (hlm. 1).
- Ribbon terdiri dari tab, grup, dan tombol, dengan dialog box launcher untuk pengaturan lanjutan (hlm. 2-3).
- Ada tiga opsi tampilan Ribbon: Auto-hide, Show Tabs, dan Show Tabs and Commands (hlm. 2).
- Dokumen baru dapat dibuat kosong atau dari template (hlm. 5-6).
- Penyimpanan ke doc, docx, atau PDF dilakukan lewat Save As type (hlm. 9).
- Proteksi dokumen memakai password to open dan password to modify (hlm. 9-10).
- Tab Home, Insert, Design, Layout, dan References masing-masing memiliki grup tugas tersendiri (hlm. 11-28).

## Istilah

- Ribbon: pita menu utama berisi tab dan grup perintah.
- Quick Access Toolbar: deretan tombol akses cepat di luar Ribbon.
- dialog box launcher: tombol pembuka pengaturan lanjutan sebuah grup.
- template: kerangka dokumen siap pakai.
- watermark: teks atau gambar samar di belakang isi halaman.
- header dan footer: area berulang di atas dan bawah setiap halaman.
- table of contents: daftar isi otomatis.
- footnote: catatan di bagian bawah halaman.
- caption: keterangan pada gambar atau tabel.
