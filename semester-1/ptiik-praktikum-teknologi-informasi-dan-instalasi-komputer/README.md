# Praktikum Teknologi Informasi dan Instalasi Komputer

Folder `ptiik-praktikum-teknologi-informasi-dan-instalasi-komputer`, semester 1.

## Overview

Praktikum ini membahas pengenalan virtual machine, instalasi dan penggunaan Linux di VirtualBox, instalasi Windows, instalasi Ubuntu, cloning disk dengan Clonezilla, serta aplikasi perkantoran Microsoft Word, Excel, dan PowerPoint. Setiap pertemuan punya modul praktikum sendiri, dan sebagian disertai laporan di subfolder `report/`.

Berkas yang berlaku sepanjang semester adalah kontrak perkuliahan dan modul gabungan PTIIK, keduanya disimpan di `00-materials/`. Modul untuk tiap pertemuan masuk ke folder pertemuan masing-masing.
