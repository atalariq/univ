# Pertemuan 13: Modul Pelatihan MS PowerPoint

Modul ini memandu pembuatan presentasi dengan Microsoft PowerPoint, dimulai dari cara menjalankan aplikasi lewat tombol Start lalu ikon PowerPoint. Presentasi baru dibuat melalui File dan New Presentation, dan judul presentasi dapat langsung dituliskan pada slide pertama (hlm. 3-4). Slide baru ditambahkan dari tab Home melalui tombol di samping New Slide, lalu dipilih layout yang sesuai. Teks diisi di dalam text box, gambar disisipkan lewat tab Insert dan Pictures dengan pilihan sumber seperti stock Images, tabel dibuat lewat Insert Table dengan penentuan jumlah baris dan kolom, dan objek lain ditambahkan lewat tombol Shapes lalu digambar pada slide (hlm. 4-9).

Tampilan kerja diatur oleh empat tombol di kanan bawah. Normal View menampilkan thumbnail di kiri dan slide besar di tengah, Slide Sorter View menampilkan semua slide kecil dalam susunan baris dan kolom, Reading View dipakai membaca isi slide aktif, dan Slide Show View menampilkan presentasi layar penuh mulai dari slide yang dipilih (hlm. 10-12). Saat presentasi berjalan, Page Down menuju slide berikutnya, Page Up kembali ke slide sebelumnya, dan Esc atau klik kanan lalu End Show mengakhiri presentasi (hlm. 13). Slide dapat dipindahkan dengan menyeret thumbnail, dihapus dengan tombol Delete atau menu Delete Slide, diduplikasi lewat Duplicate Slide yang hasilnya disisipkan setelah slide asli, disisipkan sebagai slide baru dengan Enter pada thumbnail, atau disalin lewat Copy dan Paste dengan pilihan Use Destination Theme, Keep Source Formatting, atau Picture (hlm. 14-16).

Latar belakang slide diatur lewat Format Background dengan pilihan Solid fill, Gradient fill, Picture or texture fill, dan Pattern fill; gambar latar dapat diambil dari berkas maupun daring (hlm. 17-18). Template dipakai dengan mencari tema lewat File dan New, sedangkan penerapan template pada slide yang sudah ada dilakukan dengan menyalin slide ke berkas baru bertemplat lalu memilih Use Destination Theme saat menempel (hlm. 18-20). Rehearse Timings pada Slide Show dipakai untuk mengukur durasi tiap slide; pengatur waktu dapat dijeda, diulang, dan disimpan, dan timing yang tersimpan membuat slide berpindah otomatis kecuali diatur Manual pada Set Up Slide Show (hlm. 21-23). Skema warna diatur lewat Design dan Format Background dengan Apply to All atau Reset Background (hlm. 23). Penyimpanan memakai Ctrl+S atau File lalu Save, dan Save As dengan F12 dapat mengubah format ke PPT, PPTX, PDF, dan lainnya; penyimpanan ke OneDrive mengaktifkan AutoSave dan Version History (hlm. 24-26).

## Poin kunci

- Presentasi baru dibuat lewat File lalu New Presentation (hlm. 3).
- Slide baru ditambahkan dari Home dengan pilihan layout (hlm. 4-5).
- Empat mode tampilan: Normal, Slide Sorter, Reading, dan Slide Show (hlm. 10-12).
- Duplicate Slide menaruh salinan tepat setelah slide aslinya (hlm. 15).
- Format Background menyediakan solid, gradient, picture or texture, dan pattern fill (hlm. 18).
- Rehearse Timings mengukur durasi presentasi dan dapat disimpan sebagai timing otomatis (hlm. 21-22).
- Save As dengan F12 dapat mengubah format berkas presentasi (hlm. 26).

## Istilah

- layout: susunan placeholder pada slide.
- thumbnail: tampilan mini slide pada panel kiri.
- Slide Sorter: mode tampilan seluruh slide dalam ukuran kecil.
- Slide Show: mode presentasi layar penuh.
- Format Background: pengaturan latar belakang slide.
- template: berkas contoh berisi desain dan tata letak siap pakai.
- Rehearse Timings: fitur pengukuran durasi presentasi per slide.
- timing: alokasi waktu yang membuat slide berpindah otomatis.
- AutoSave: penyimpanan otomatis berkas di penyimpanan daring.
