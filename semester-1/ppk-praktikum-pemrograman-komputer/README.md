# Praktikum Pemrograman Komputer

Folder `ppk-praktikum-pemrograman-komputer`, semester 1.

## Overview

Praktikum ini berisi latihan pemrograman Python yang mengikuti modul 1 sampai 11. Modul 1 membahas algoritma dan flowchart, modul 2 dasar Python, lalu tipe data dan struktur data, input dan output, percabangan, perulangan, list dan sorting, function, sorting, serta searching, error, dan file handling.

Setiap folder pertemuan menyimpan modul praktikum, dan sebagian juga menyimpan pekerjaan praktikum di subfolder `src/` serta laporan di `report/`. Modul 1 dan modul 2 sama-sama diletakkan di `p03-pemrograman-python` karena modul 1 tidak punya pertemuan praktikum sendiri.

Folder ini belum punya materi semester, jadi semua berkas disimpan di folder pertemuan.
