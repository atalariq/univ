# Pertemuan 3: Pemrograman Python

Modul pertama membahas algoritma dan flowchart sebagai cara menyatakan penyelesaian masalah sebelum menulis kode. Algoritma didefinisikan sebagai proses umum untuk mengubah input menjadi output yang diharapkan, dan satu masalah dapat diselesaikan dengan beberapa algoritma sehingga pemilihannya memengaruhi waktu serta memori komputasi (hlm. 1). Flowchart memakai empat simbol inti: terminator untuk awal dan akhir, process untuk aksi, decision untuk percabangan, dan input/output untuk parameter maupun hasil (hlm. 2). Aturannya, flowchart dimulai dari MULAI dan berakhir di SELESAI, simbol process dan input/output masing-masing menghasilkan satu panah keluar, sedangkan decision menghasilkan tepat dua panah untuk YA dan TIDAK (hlm. 2-3). Contoh yang dipakai adalah luas permukaan tabung, pengecekan kelipatan 5, dan penjumlahan 1 sampai N, dengan praktik menggambar di draw.io lalu mengekspornya ke PNG (hlm. 3-7).

Modul kedua masuk ke Python 3. Program dibangun dari lima jenis instruksi dasar: input, output, operasi matematika, percabangan, dan pengulangan (hlm. 1). Untuk menjalankan program diperlukan interpreter, dan modul menyarankan Anaconda karena di dalamnya sudah tersedia interpreter Python, IDE Spyder dan Jupyter, serta paket pendukung komputasi (hlm. 1-2). Program ditulis di Spyder dengan ekstensi .py lalu dijalankan lewat tombol Run (hlm. 3). Variabel diperkenalkan sebagai nama untuk sebuah nilai hasil assignment, dan perbandingan `print(x)` dengan `print("x")` dipakai untuk menunjukkan bahwa bentuk kedua mencetak teks, bukan nilai variabel (hlm. 3-4). Operator aritmatika yang dibahas meliputi `+`, `-`, `*`, `/`, `//` untuk pembagian bulat, `%` untuk modulo, dan `**` untuk pangkat, termasuk contoh bahwa nilai variabel dapat diperbarui (hlm. 4-5). Praktik di bagian akhir mengubah suhu Fahrenheit ke Celsius, sedangkan latihan dan quiz meminta luas permukaan tabung, digit tengah bilangan tiga angka, volume kerucut, dan jumlah digit (hlm. 5).

## Poin kunci

- Algoritma adalah proses umum penyelesaian masalah, dan pemilihan algoritma memengaruhi waktu serta memori (hlm. 1).
- Simbol flowchart terdiri dari terminator, process, decision, dan input/output; decision selalu bercabang dua (hlm. 2).
- Flowchart mulai dan selesai di terminator, dan semua variabel yang dipakai harus muncul di simbol input/output (hlm. 2-3).
- Lima instruksi dasar pemrograman adalah input, output, operasi matematika, percabangan, dan pengulangan (hlm. 1).
- Anaconda dipakai karena membawa interpreter, Spyder, dan Jupyter dalam satu paket (hlm. 1-2).
- `//`, `%`, dan `**` berturut-turut adalah pembagian bulat, sisa bagi, dan pangkat (hlm. 4).

## Istilah

- algoritma: urutan langkah penyelesaian masalah.
- flowchart: diagram alir bersimbol dan berarah untuk menjelaskan suatu proses.
- terminator: simbol penanda awal atau akhir flowchart.
- decision: simbol percabangan berisi kondisi yang dijawab YA atau TIDAK.
- interpreter: program yang mengeksekusi kode sumber secara langsung.
- assignment: pemberian nilai ke sebuah variabel.
- modulo: sisa hasil pembagian bulat.
