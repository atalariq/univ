# Matematika Diskrit

Folder `matdis-matematika-diskrit`, semester 1.

## Overview

Mata kuliah ini membahas topik matematika diskrit seperti logika, himpunan, relasi, fungsi, kombinatorika, dan graf. Materi pertemuan yang tersimpan membahas minimum spanning tree, salah satu topik graf.

Dua buku rujukan disimpan di `00-materials/`, yaitu Discrete Mathematics with Applications karya Susanna Epp dan Matematika Diskrit karya Rinaldi Munir. Berkas materi pertemuan memakai nama berbasis tanggal karena nomor pertemuannya tidak tercatat.
