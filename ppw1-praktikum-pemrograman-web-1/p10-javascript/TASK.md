# PPW1: Pertemuan 10 - Javascript

## Modul Bab 10

1. Silahkan buat 1 file html yang isinya memanggil code javascript yang berasal dari
   embed, inline, eksternal. (Isi teks html dan javascript bisa anda variasikan sendiri).
2. Silahkan buat 1 file html yang isinya menampilkan output dari javascript yang dibuat menggunakan
   Fungsi console.log(), Fungsi alert(), Fungsi document.write(), dan innerHTML.
   (Isi teks html dan javascript bisa anda variasikan sendiri).

## Modul Bab 11

1. Tulis code yg berisikan javascript berisikan prompt() meminta input 2 bilangan.
   Kemudian buat cek kondisi kedua bilangan tersebut. Tampilkan hasilnya.
   EX: BILANGAN KE-1 LEBIH BESAR DARI BILANGAN KE-2
2. Tulis code yg berisikan javascript menanyakan apakah anda praktikan PPW1?, jika iya
   ditanya Nama, NIM, dan Angkatan. Lalu tampilkan hasilnya dalam tabel (menggunakan
   bootstrap), jika tidak tampil tulisan “Anda bukan praktikan PPW1, anda tidak boleh
   masuk!”.
3. Kalkulator sederhana, mekanisme kalkulatornya sesuai kreasi anda.
