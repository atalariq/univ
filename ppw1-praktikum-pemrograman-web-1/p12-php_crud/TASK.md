# PPW1: P12 - PHP CRUD

1. Buatlah minimal satu program CRUD (Create, Read, Update, Delete) pada satu
   tabel database menggunakan Bootstrap sebagai framework frontend agar
   tampilan lebih responsif dan menarik.
2. Lakukan export database dari phpMyAdmin dalam bentuk file .sql,
   kemudian simpan file tersebut ke dalam folder project. Setelah project selesai,
   upload/push project ke GitHub dan cantumkan link repository pada laporan praktikum.
3. Kerjakan juga tugas praktikum pada modul "PHP - Lanjutan":
   1. Buat form Konversi Nilai: pengguna memasukkan nilai angka (0-100), PHP
      menampilkan grade huruf (A/B/C/D/E) beserta deskripsinya. Tampilkan dengan
      warna berbeda untuk setiap grade.
   2. Buat form Pendataan Mahasiswa dengan field: Nama, NIM, Prodi (dropdown), IPK
      (angka), Semester. Validasi semua field dan tampilkan data yang sudah
      diisi kembali di halaman (pastikan aman dari XSS).
      Hitung dan tampilkan juga predikat kelulusan berdasarkan IPK.
