Modul Praktikum CRUD dengan PHP

Panduan Lengkap Membuat Aplikasi Create, Read, Update, Delete

Pendahuluan

CRUD adalah singkatan dari Create, Read, Update, dan Delete yang merupakan operasi dasar dalam pengelolaan data pada aplikasi web. Operasi-operasi ini sangat penting dalam pengembangan aplikasi yang melibatkan basis data.

Pada modul praktikum ini, kita akan belajar membuat aplikasi CRUD sederhana menggunakan PHP dan MySQL sebagai database. Aplikasi ini akan memiliki fungsionalitas:

  • Create - Menambahkan data baru ke database
  • Read - Menampilkan data dari database
  • Update - Mengubah data yang sudah ada
  • Delete - Menghapus data dari database

Prasyarat

Sebelum memulai praktikum ini, pastikan Anda telah menyiapkan hal-hal berikut:

  • Web server lokal (XAMPP, WAMP, MAMP, atau Laragon)
  • Text editor (Visual Studio Code, Sublime Text, atau Notepad++)
  • Browser web (Chrome, Firefox, atau Edge)
  • Pengetahuan dasar HTML, CSS, PHP, dan MySQL

Catatan: Pastikan web server lokal Anda sudah berjalan dengan baik dan layanan MySQL aktif.

Langkah 1: Membuat Database

Pertama, kita perlu membuat database dan tabel untuk menyimpan data. Ikuti langkah-langkah berikut:

  1. Buka phpMyAdmin di browser (biasanya di http://localhost/phpmyadmin)
  2. Klik pada tab "SQL" untuk menjalankan query SQL
  3. Jalankan query berikut untuk membuat database dan tabel:
SQL
CREATE DATABASE praktikum_crud;

USE praktikum_crud;

CREATE TABLE mahasiswa (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nim VARCHAR(15) NOT NULL,
    nama VARCHAR(100) NOT NULL,
    jurusan VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL,
    alamat TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Langkah 2: Membuat Struktur Folder Proyek

Mari membuat struktur folder untuk proyek CRUD kita:

  1. Buat folder dengan nama praktikum_crud di dalam direktori htdocs (untuk XAMPP) atau www (untuk WAMP/MAMP)
  2. Di dalam folder tersebut, buat file-file berikut:
    • config.php - Untuk konfigurasi database
    • index.php - Halaman utama (Read)
    • tambah.php - Halaman untuk menambah data (Create)
    • edit.php - Halaman untuk mengedit data (Update)
    • hapus.php - Script untuk menghapus data (Delete)

Langkah 3: Membuat Koneksi Database

Buat file config.php untuk mengatur koneksi ke database:

config.php
<?php
// Konfigurasi database
$host = "localhost";
$username = "root";
$password = ""; // Sesuaikan dengan password MySQL Anda, biasanya kosong
$database = "praktikum_crud";

// Membuat koneksi
$conn = mysqli_connect($host, $username, $password, $database);

// Cek koneksi
if (!$conn) {
    die("Koneksi gagal: " . mysqli_connect_error());
}
?>

Perhatian: Dalam lingkungan produksi, jangan gunakan username dan password default seperti di atas. Selalu gunakan kredensial yang aman.

Langkah 7: Membuat Script Hapus Data (Delete)

Buat file hapus.php untuk menghapus data mahasiswa:

hapus.php
<?php
// Include file koneksi database
include_once("config.php");

// Cek apakah ada ID yang dikirimkan
if(isset($_GET['id'])) {
    $id = $_GET['id'];
    
    // Query untuk menghapus data
    $result = mysqli_query($conn, "DELETE FROM mahasiswa WHERE id=$id");
    
    // Redirect ke halaman utama
    header("Location: index.php");
} else {
    // Jika tidak ada ID yang dikirimkan, kembali ke halaman utama
    header("Location: index.php");
}
?>

Langkah 8: Menguji Aplikasi

Setelah semua file dibuat, saatnya menguji aplikasi CRUD yang telah kita buat:

  1. Buka browser dan akses http://localhost/praktikum_crud/
  2. Pada halaman utama, klik tombol "Tambah Mahasiswa" untuk menambahkan data baru
  3. Isi formulir dengan data mahasiswa yang valid, lalu klik "Simpan"
  4. Data akan ditampilkan di halaman utama
  5. Coba lakukan operasi Edit dan Hapus untuk memastikan semua fungsi berjalan dengan baik

Tips: Jika aplikasi berjalan dengan baik, Anda telah berhasil membuat aplikasi CRUD sederhana menggunakan PHP dan MySQL!

Penjelasan Konsep CRUD

Create (Membuat)

Operasi Create digunakan untuk membuat atau menambahkan data baru ke dalam database. Dalam aplikasi kita, operasi ini dilakukan melalui file tambah.php yang berisi form untuk menambahkan data mahasiswa. Data yang dimasukkan akan disimpan ke database menggunakan query SQL INSERT.

Read (Membaca)

Operasi Read digunakan untuk membaca atau menampilkan data dari database. Dalam aplikasi kita, operasi ini dilakukan melalui file index.php yang menampilkan semua data mahasiswa dalam bentuk tabel. Data diambil dari database menggunakan query SQL SELECT.

Update (Memperbarui)

Operasi Update digunakan untuk memperbarui atau mengubah data yang sudah ada di database. Dalam aplikasi kita, operasi ini dilakukan melalui file edit.php yang berisi form untuk mengedit data mahasiswa. Data yang diubah akan diperbarui ke database menggunakan query SQL UPDATE.

Delete (Menghapus)

Operasi Delete digunakan untuk menghapus data dari database. Dalam aplikasi kita, operasi ini dilakukan melalui file hapus.php yang menghapus data mahasiswa berdasarkan ID. Data dihapus dari database menggunakan query SQL DELETE.

Keamanan Aplikasi

Aplikasi CRUD sederhana yang telah kita buat di atas masih rentan terhadap beberapa masalah keamanan, seperti SQL Injection. Untuk aplikasi yang akan digunakan di lingkungan produksi, sebaiknya tambahkan beberapa langkah keamanan berikut:

Menggunakan Prepared Statements

Prepared statements membantu mencegah SQL Injection dengan memisahkan SQL query dari data yang dikirimkan pengguna:

Contoh Prepared Statement
// Contoh prepared statement untuk INSERT
$stmt = $conn->prepare("INSERT INTO mahasiswa(nim, nama, jurusan, email, alamat) VALUES(?, ?, ?, ?, ?)");
$stmt->bind_param("sssss", $nim, $nama, $jurusan, $email, $alamat);

// Set parameter
$nim = $_POST['nim'];
$nama = $_POST['nama'];
$jurusan = $_POST['jurusan'];
$email = $_POST['email'];
$alamat = $_POST['alamat'];

// Eksekusi query
$stmt->execute();

Validasi Input

Selalu validasi semua input pengguna sebelum diproses. Dalam modul ini kita sudah menerapkan validasi dasar, namun untuk aplikasi yang lebih aman, Anda bisa menambahkan validasi lebih lanjut seperti sanitasi data dan validasi format.

Penanganan Error

Implementasikan penanganan error yang baik untuk mencegah informasi sensitif terlihat oleh pengguna. Dalam lingkungan produksi, jangan tampilkan detail error database kepada pengguna.

Tugas Tambahan

Untuk meningkatkan pemahaman Anda tentang CRUD dengan PHP, coba lakukan pengembangan berikut pada aplikasi proyek anda:

  1. Tambahkan fitur pencarian data
  2. Implementasikan pagination untuk menampilkan data per halaman
  3. Tambahkan fitur upload foto
  4. Tambahkan validasi data yang lebih lengkap
  5. Implementasikan autentikasi user (login/logout) sebelum bisa mengakses aplikasi
